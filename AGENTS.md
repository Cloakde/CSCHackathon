# LiveLecture AI Agent Instructions

Before working in this repository:

1. Read [docs/MULTI_AGENT_WORKFLOW.md](docs/MULTI_AGENT_WORKFLOW.md).
2. Read [docs/MILESTONE_PLAN.md](docs/MILESTONE_PLAN.md).
3. Read the assigned task contract and relevant ADRs.
4. Confirm the exact base commit and owned paths.

Do not self-assign tasks, modify unowned paths, expose credentials, use real classroom data in tests, or present Simulation Mode as live capture.

The Coordinator is the sole writer of [docs/TASK_BOARD.md](docs/TASK_BOARD.md) while the repository uses the file-based tracker.
