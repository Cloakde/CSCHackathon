# Keep learning after the lecture

These tools live in the separate private MeltingPot copy. The Chrome extension remains the during-class part of the product. No API key is needed for the sample demonstration.

Use the existing [setup guide](../TASK-308/RELEASE.md) to start the two local apps. Finish the sample lecture in the extension and choose **Open in MeltingPot**. The labeled browser rehearsal is also available, but is not proof of Chrome installation.

## Practice without losing your place

Choose a confusing moment, write your answer and compare it with the explanation. Switching to another moment keeps the first answer and explanation on this page. Returning to a saved exercise does not generate it again.

Use **Mark for review** for a concept you still want to work on, or **Mark as clearer** when it makes more sense. **Show review queue** focuses on unrated concepts and those you marked for review. These are your own judgments, not grades or a claim that you have mastered the material.

## Use the flashcards

Each card asks you to explain one concept that confused you. **Show source passages** reveals the exact supporting words from the lecture. Open a passage to see it in the transcript, then choose **Return to flashcards**. Use **Needs review** or **Feels clearer** to choose what to revisit. **Review again** starts another round using your review queue.

## Save and reopen later

1. Choose **Download study file** before closing the page. The JSON file contains the transcript, confusing moments, saved exercises, written answers, bookmarks and review ratings. No audio recording or API key is included.
2. Keep the file somewhere appropriate for private lecture material. Nothing is saved automatically, and downloading again creates a new copy of your latest progress.
3. Later, start only the guarded MeltingPot preview and visit its lecture home page at `http://127.0.0.1:3111/lectures`. Select **Open study file**. The original LiveLecture service can be stopped or its session deleted.
4. Work with your saved exercises, flashcards and notes. A file cannot generate exercises that were never saved. Download a new copy to keep additional progress.
5. **Close study pack** clears the page. It does not delete the file on your device or contact the original lecture service. Delete downloaded files yourself when no longer needed.

Imported files are checked for valid structure and matching references, but anyone with the file can edit its words. Their source and AI claims are not independently verified. Imports are limited to 2 MB, 300 transcript passages and 100 confusing moments. Files are read in the page and are not uploaded. This requires the local MeltingPot app; it is not a standalone app inside the JSON file.

The automated journey covers these behaviors with synthetic material. Human Chrome, visual/accessibility, learner and subject review, real Gemini/Scribe checks and competition access remain separate acceptance tasks.
